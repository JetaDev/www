# Repaso para el Examen - DWEC

## Actividad 1: Funciones y Arrays

### Descripción
Este ejercicio trabaja con **arrays numéricos** utilizando **JavaScript simple**.

### Archivo:
- `actividad1.html` - TODO EN UNO: HTML + CSS + JavaScript

### Funciones implementadas:

1. **numeroMasAlto(array)**: Devuelve el valor más alto del array
2. **numeroImpares(array)**: Cuenta cuántos números impares hay
3. **mediaAritmetica(array)**: Calcula la media aritmética
4. **moda(array)**: Encuentra el valor que más se repite
5. **numeroPrimos(array)**: Cuenta cuántos números primos hay

### Cómo ejecutar:
1. Abre el archivo `actividad1.html` en tu navegador
2. Haz clic en el botón "Ejecutar Funciones"
3. Verás los resultados de todas las funciones

### Array de prueba usado:
```javascript
[2, 5, 7, 3, 5, 8, 11, 5, 13, 4, 7, 2, 5]
```

### Resultados esperados:
- Número más alto: 13
- Números impares: 8
- Media aritmética: 5.92
- Moda: 5 (aparece 4 veces)
- Números primos: 5 (son: 2, 5, 7, 11, 13)

### Notas:
- Todo el código está en un solo archivo
- JavaScript simple, sin módulos
- Fácil de entender y modificar
